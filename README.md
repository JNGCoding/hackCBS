
  # Health-Tech AI Chatbot Dashboard

  This is a code bundle for Health-Tech AI Chatbot Dashboard. The original project is available at https://www.figma.com/design/hnHZKFlW39gotAGgCFvLvm/Health-Tech-AI-Chatbot-Dashboard.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm install react-dom` to install react-dom.

  Run `npm install @clerk/clerk-react` to install clerk.

  Run `npm run dev` to start the development server.

  ## How to execute ?

  Simply run the start.bat file to run both the backend and frontend together!
  Or you can run them seperately via VSCode.
